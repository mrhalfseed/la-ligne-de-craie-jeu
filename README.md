# La Ligne de craie

Une bande dessinée interactive sur la Grande Guerre : Peio, un jeune berger basque, de l'estive de 1914 au Chemin des Dames.

Ce dossier contient uniquement la version jouable du jeu, publiée avec GitHub Pages.

- Les images ont été créées avec l'aide d'une intelligence artificielle, sous la direction de l'auteur.
- Musiques : Maurice Ravel, *Pavane pour une infante défunte*, au piano par Thérèse Dussaut (licence CC BY-SA 2.0, Wikimedia Commons) ; Gustav Holst, *Mars*, par l'United States Air Force Band (domaine public).
- Photos d'époque : domaine public (Wikimedia Commons, Bibliothèque nationale de France, Archives nationales).
